Intern Assignment: RAG-Based AI Tutor With Images

Goal
Build a small AI Tutor Chatbot that uses RAG to answer questions from a chapter PDF and automatically shows relevant images during explanations.

What You Need to Build
1. PDF → Text Extraction
- User uploads a chapter PDF (You can use sound chapter pdf present here).
- Extract text and convert it into chunks for retrieval.

2. RAG Pipeline
Generate embeddings for all text chunks (OpenAI/Gemini/Groq free tier or any open-source embeddings model).
Store embeddings in local storage (JSON or simple vector DB like FAISS).
On every user question:
- Retrieve the most relevant text chunks (K = 3–5).
- Send them along with the user query to an LLM.
- Return a grounded answer (should use the retrieved content).

3. Image Metadata + Embeddings
Create a small JSON file with 4-8 diagrams for the topic (You can use these images):
{
  "id": "img_001",
  "filename": "bell.png",
  "title": "Bell Vibration",
  "keywords": ["bell", "vibration", "sound"],
  "description": "Bell vibration diagram"
}
Also generate embeddings for descriptions/keywords.

4. Image Retrieval + Display
Whenever the AI returns an answer:
- Extract keywords OR use embedding similarity
- Identify the most relevant image (1 per answer)
- Return the image along with the text response


Frontend Requirements
- File upload UI (PDF upload)
- Simple chat interface (user message → AI response)
- AI responses should include:
	- Answer text
	- An image (if available), displayed inline


No styling required beyond basic layout.
Backend Requirements
Use FastAPI / Node.
Required endpoints:
- POST /upload → extract text → create embeddings → return topicId
- POST /chat → retrieve chunks → generate answer
- GET /images/:topicId → return metadata

Deliverables
1. GitHub repo
2. Working chatbot (deployed or local run steps)
3. README with:
   - RAG pipeline explanation
   - Image retrieval logic
   - Prompts used
4. Demo video (2–4 min)

Evaluation
- Correct RAG implementation
- Grounded answers
- Image retrieval correctness
- Clean UI
- Clear documentation
